# MarketForge

MarketForge is a production-style real-time paper trading and simulated exchange platform.

## Technology Stack

- React + TypeScript — Trading Terminal
- Node.js + Express — API Gateway / BFF + WebSocket Edge
- Java + Spring Boot — Trading, Risk and Portfolio Services
- C++20 — Matching Engine and Order Book
- Python — Quantitative Analytics and Backtesting
- PostgreSQL — Authoritative Transactional Database
- Redis — Hot State and Caching
- Kafka — Event-Driven Backbone
- Docker — Container Packaging
- Kubernetes — Deployment and Orchestration
- Helm — Kubernetes Deployment
- AWS — Cloud Deployment
- Git + GitHub — Source Control and CI/CD
